02 · THE LOOP

      
A commitment, an auction, a settlement.

      
And the AI that feeds the first and drives the second. Four stages, one chain. Nothing here is trusted that does not have to be.

    

    

      
01 · PARSE
Declare
A sentence becomes an IntentSpec in tickers and percents. A compiler resolves symbols against the onchain catalog. A hallucinated ticker dies here, not in a transaction.

      
02 · COMMIT
Hash, don’t instruct
IntentRegistry stores the outcome hash and the policy hash — not the contents. The id is derived onchain from those hashes, the owner, a salt and the timing.

      
03 · AUCTION
Bind the how
Solvers bid a fee, an ETA, and a vector of guaranteed outputs. Winning means being held to that vector. A bonded coordinator can pick; a dominated pick can be slashed.

      
04 · SETTLE
Measure, then pay
IntentSettlement sizes every leg from committed weights, calls allowlisted routers, and checks balance deltas on the recipient. The solver never supplies amounts.

    

    

      

        

          
What is not trusted

          

            
—Not the solver. It picks routes. It cannot pick amounts, recipients, weights or floors.

            
—Not the coordinator, for funds. It can pick a worse-but-valid solver, so it posts a bond.

            
—Not the mempool. Drafts are verified against the onchain commitment before anyone plans against them.

            
—Not the language model. It never emits an address or a wei amount.

          

        

        

          
You are trusting the router allowlist, the RWA attestors, and the contracts. Everything else is designed to be wrong without being able to hurt the outcome.

04 · AGENTS

      
Agents declare. Agents can also solve.

      
The SDK is one import from a sentence to a settled position. Open questions are not signed on the user’s behalf.

    

    

      

        
@intentos/sdk

        
import { IntentAgent, IntentOSClient } from "@intentos/sdk";

const agent = new IntentAgent(client);

const { intentId, explanation, submitted, heldFor } =
  await agent.declare(
    "put 5,000 USDT into NVDA and AAPL, 60/40, only attested assets"
  );

// Open questions are not signed on the user's behalf.
if (!submitted) console.log(heldFor);

await agent.track(intentId);

        
Clarifications hold the intent. Recurrence is offchain in v0.1 — the agent runtime submits once per period. Conditions fail closed: no observation, no serve.

      

      

        
Why agents first

        

          
01They already speak in outcomes. Encoding four swaps is a bug farm.

          
02Policy is committed: spend cap, fee cap, reputation floor, attested-only.

          
03The coordinator closes auctions so the agent does not have to stay online.

          
04A solver that wins and walks loses reputation. The next intent can require a floor.
